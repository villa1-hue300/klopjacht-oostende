🔧 Eenmalige koppeling

Vul de Project URL en publishable / anon key van Supabase in. Gebruik NOOIT de service_role of secret key. Deze configuratie wordt alleen in deze browser bewaard.

🔐 Aanmelden

Iedere speler gebruikt een eigen e-mailadres. Voor kinderen kan een afzonderlijk, door een ouder beheerd e-mailadres gebruikt worden. Eén e-mailadres/account kan maar één speler claimen.

Open de link in je mail op hetzelfde toestel. Controleer in Supabase Authentication → URL Configuration de Site URL en redirect URLs.

🎟️ Wie ben jij?

Je hebt een persoonlijke uitnodigingscode nodig die de spelleider privé bezorgt. Zo kan niemand onder jouw naam stemmen.

🐽 Kies je kant

Je keuze is geheim en na bevestiging definitief.

Deze pincode is een extra bevestiging, geen vervanging voor je veilige e-mailaanmelding. Deel hem niet.
